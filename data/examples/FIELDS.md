# 字段说明与示例数据

默认演示文件 `public_demo.csv` 是完全独立模拟示例，仅含虚构的 G01—G05 五类。它使用公开代码中的固定参数和随机种子生成，未读取任何真实生产记录、汇总统计或脱敏副本；每类固定 2,000 条不表示真实产量。`data_status` 标注“完全独立模拟示例；非真实生产记录”。以下字段含义描述工作台标准口径，演示模式下不代表真实测量。

`simulated_slabs.csv` 包含 12,000 条模拟记录，随机种子为 1880。钢种为 DEMO-A/B/C。温降由人为设置的公式和噪声生成，数据包含一条尺寸缺失和两条异常记录，用于展示质量检查。它不能支持真实工业结论。

| 标准字段 | 含义 | 工作台单位 | 示例原始字段名 |
| --- | --- | --- | --- |
| slab_id | 真实板坯编号，可缺失 | 文本 | 未提供 |
| steel_grade | 钢种 | 文本 | 出钢记号 |
| produced_at | 生产 / 出钢时间 | 原记录本地时间 | 出钢时间 |
| length / width / thickness | 板坯长 / 宽 / 厚 | mm | 长度 / 宽度 / 厚度 |
| rough_thickness | 粗轧厚度 | mm | 粗轧厚度 |
| rolling_thickness | 轧制厚度 | mm | 轧制厚度 |
| exit_temp | 出炉温度 | °C | 出钢温度 |
| charge_temp | 装钢温度 | °C | 装钢温度 |
| rough_temp / finish_temp | 粗轧 / 精轧温度 | °C | 未提供 |
| temp_drop | 粗轧温降 | °C | 粗轧温降 |
| process_time | 粗轧过程时间 | s | 粗轧过程时间 |
| furnace_time | 在炉时间 | min | 在炉时间 |
| weight | 重量 | kg | 重量 |
| furnace | 加热炉号 | 文本 | 炉号 |

输入尺寸支持 mm、cm、m；温度支持 °C、K；时间支持 s、min；重量支持 kg、t。温差从 K 转 °C 时数值不变。字段缺失保留为空，不用零或均值填补。日期保留本地时间，不推测时区；无法解释的纯 Excel 数字日期需要先转成日期文本再导入。

每条记录附加 `record_id`、`source_file`、`source_sheet`、`source_row` 与质量标记。编号缺失时，以源表行号显示“记录 N”；内部记录标识仅用于图表、表格、三维选中一致性，不冒充真实板坯编号。

导入支持 `.xlsx` 和 `.csv`，CSV 编码自动尝试 UTF-8 与 GB18030。旧 `.xls` 可先另存为 `.xlsx`。首版每次最多 10 个文件，每个文件最多 40 个工作表、100 MB；单表和最终数据集最多 50 万行。原始文件保存于本地 `runtime/uploads/`。
